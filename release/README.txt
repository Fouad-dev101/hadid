HADID  -  quick start
=====================

1. Extract this whole zip somewhere (right-click > Extract All).
2. Double-click  Install-Hadid.bat
3. Open Hadid from the Desktop or Start menu.

Windows may say "Windows protected your PC" the first time, because the app is not
signed with a paid certificate. Click "More info", then "Run anyway". The source code
is public, so you can check it or build it yourself.

Your training data stays on your computer, in %APPDATA%\Hadid. Nothing is uploaded.
To remove Hadid: delete %LOCALAPPDATA%\Programs\Hadid and the two shortcuts.
Your data folder is kept unless you delete it too.
