# Third-party software

Hadid bundles these open-source pieces. Thanks to their authors.

| Component | Used for | License |
|---|---|---|
| [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) | SQLite for the Windows app, pure Go | BSD-3-Clause |
| [SQLite](https://sqlite.org) | the database format | Public domain |
| [sql.js](https://github.com/sql-js/sql.js) | SQLite in WebAssembly for the Android app | MIT |
| [Capacitor](https://capacitorjs.com) | Android app shell and plugins | MIT |
| Big Shoulders Display, Instrument Sans, JetBrains Mono, Reem Kufi | fonts, via [Fontsource](https://fontsource.org) | SIL Open Font License 1.1 |

The fonts are embedded as `.woff2` files in `web/fonts/` and may be redistributed under the OFL.
